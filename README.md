🧠 Teen Mental Health & Social Media Impact Analysis
📌 Project Overview

This project analyzes teen mental health and social media usage data using Tableau to explore relationships between social media behavior, lifestyle factors, academic performance, and mental health indicators.

The project transforms survey-based data into an interactive Tableau dashboard and story, allowing users to explore patterns across age, gender, social media platforms, sleep, academic performance, physical activity, stress, anxiety, addiction, and depression indicators.

Disclaimer: This project is intended for educational and data analytics purposes. The analysis identifies patterns and associations within the dataset and should not be interpreted as medical or clinical conclusions.

🎯 Project Objectives

The main objectives of this project are to:

Analyze daily social media usage among teenagers
Compare social media usage across different platforms
Explore relationships between age and social media usage
Examine the relationship between sleep and academic performance
Analyze stress and anxiety levels across age groups
Explore differences across genders
Understand patterns between social media behavior and mental health indicators
Present the analysis through an interactive Tableau dashboard

🛠️ Tools & Technologies
Tableau – Data analysis, visualization, dashboard and story development
CSV Dataset – Source data

📊 Dataset

The project uses:

Teen_Mental_Health_Dataset.csv

The dataset contains the following variables:

Field	Description
age	Age of the participant
gender	Gender of the participant
daily_social_media_hours	Average daily social media usage
platform_usage	Social media platform used
sleep_hours	Reported sleep hours
screen_time_before_sleep	Screen time before sleeping
academic_performance	Academic performance indicator
physical_activity	Physical activity indicator
social_interaction_level	Level of social interaction
stress_level	Reported stress level
anxiety_level	Reported anxiety level
addiction_level	Social media/addiction indicator
depression_label	Depression-related dataset label

🔄 Data Analysis Workflow
1. Data Preparation

The dataset was connected to Tableau and prepared for analysis.

2. Data Exploration

The available demographic, social media, lifestyle, academic, and mental health variables were explored.

3. Visualization

Different visualization techniques were selected according to the analytical question:

Bar Chart → Platform usage comparison
KPI → Average social media usage
Line Chart → Stress and anxiety by age
Scatterplot → Sleep vs. academic performance
4. Dashboard Development

The individual visualizations were combined into an interactive Tableau dashboard.

5. Story Development

A Tableau Story was included to present the analysis in a structured sequence and make the findings easier to explore.
